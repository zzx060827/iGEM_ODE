# Model / Engineering 简约讲稿

## 约 6 分钟版本

我们的治疗设想是用 AAV 递送 SINEUP，上调单倍剂量不足患者仍保留的正常等位基因。但真正的问题不是“AAV 能不能进体内”，而是它能否到达正确器官、跨过屏障、进入正确细胞，并在不造成过度脱靶的情况下产生足够久的蛋白恢复。

因此我们把过程拆成四层。第一层是全身 PBPK，追踪血液、器官血管和组织间质。第二层是细胞转导，从受体结合、内吞、早晚内体、胞质逃逸、入核、解包一直到 episome。第三层是 SINEUP 药效，episome 产生 SINEUP RNA，再改变目标蛋白水平和有效持续时间。第四层是前端，用户从疾病和基因出发，比较衣壳、给药途径、器官特异性和持久性。

我们的 Engineering 不是一次把模型写完，而是四轮 Design-Build-Test-Learn。

第一轮，原模型用统一半衰期人为制造衰减。我们改成有明确去向的血液清除、器官血管损失、间质降解和累计 sink，并用 AAV9 文献时间序列拟合器官表观半衰期。测试时，模型质量守恒误差达到数值精度。我们也学到，表观半衰期不能区分具体清除机制，所以 35% 血管、65% 间质的拆分被明确标成待校准假设。

第二轮，单看器官浓度无法解释表达。我们加入肝、肾和 CNS 的胞内链。肾脏用受限滤过和基底外侧摄取两个入口；CNS 增加 BBB 结合、内吞、跨胞运输和回收。场景测试发现，增强内体逃逸会显著提高 episome，但蛋白可能因为下游饱和而不再同比增加。这直接告诉湿实验：不能只测 vector genome，还要测 episome、RNA 和蛋白。

第三轮，我们没有把小鼠按 70 kg 简单放大，而是保留同一套方程，重新建立心肺循环、门静脉、24 个区域、301 个状态和六种给药途径。人体血容量、CSF 容积和周转可以核对，但衣壳参数仍是小鼠或 NHP 先验，所以我们称它为 reference-human projection，而不是临床预测。

第四轮，我们把 ODE 批量输出到 React 前端。二维图的横轴是目标器官相对于脱靶器官的暴露特异性，纵轴是 SINEUP-PD 算出的蛋白有效持续时间。人体图既可看绝对值，也可在同一衣壳内归一化；默认相对值用于看空间差异，但图例会提示它不能代表绝对剂量。

Contribution 主要有两个。第一是完整参数注册表，每个参数都写明数值、单位、物种、来源、证据类型、置信度和校准优先级，不再只写一个模糊的 Estimated。第二是从 ODE 到 JSON/CSV 再到交互网页的可复用流程，未来队伍可以替换参数、增加衣壳和器官，而不用重新搭整套系统。

Measurement 方面，我们把 capsid、vector genome、episome、SINEUP RNA 和蛋白定义成不同 measurand。最小实验闭环是在早期测血液和器官 vector/capsid，在后期测 episome、RNA 和蛋白，并至少留出一个时间点或剂量做外部验证。只有实验数据真正改变参数并重新排序候选，DBTL 才完整闭环。

安全性方面，我们没有用某个上市药剂量声称自己的构建安全。当前模块只把各方案的肝、肾/脾、心和 CNS 暴露与同模型 IV-AAV9 比较，再提示 ALT/AST、血小板、补体、肌酐、troponin 或 DRG/CNS 等监测重点。下一步需要产品特异的暴露-毒性数据，才能建立概率模型。

所以这套模型当前最可信的作用，是解释机制、暴露假设、缩小实验组合并明确下一步该测什么；它还不是人体给药计算器。我们认为这种明确边界、保留失败并可被实验更新的系统，比一张看起来很精确但无法追溯的预测图更符合 iGEM 的工程精神。

## 可能追问

**为什么质量守恒不能证明模型正确？** 质量守恒只证明数值收支闭合；错误参数也可以守恒。生物学正确性需要外部数据验证。

**为什么不同衣壳不是直接改最终分数？** 衣壳先验先改变 PS、Kp 和 BBB 等通量参数，再重求 ODE，最终二维坐标来自轨迹。

**人体模型与小鼠最大的区别？** 方程族相同，但人体重新定义循环拓扑、容积、血流、区域、CSF 和给药入口；参数外推仍单独标注。

**现在最需要的湿实验是什么？** 同一批样本上分层测 vector/capsid、episome、RNA 和蛋白，优先校准 transport、endosomal escape 与 SINEUP gain。
