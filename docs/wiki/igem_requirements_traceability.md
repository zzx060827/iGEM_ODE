# iGEM requirements traceability

This table maps the requested iGEM material to evidence that already exists in
the repository. It is a drafting and review aid, not a substitute for the
official Attributions Form or judging form.

| Requirement | Repository evidence | Remaining team action |
|---|---|---|
| Attribution | `attributions.md`; Git history; software, data and SVG licences | Replace every **TEAM TO VERIFY** field with names, dates and exact work before the freeze |
| Contribution | `contribution.md`; parameter registry exporter; ODE-to-JSON data contract; reproduction guide | Decide which one or two outputs will be presented as the team's principal reusable contribution |
| Engineering Success | `engineering.md`; four DBTL cycles; acceptance criteria; failed assumptions and corrected transcription cap | Add wet-lab dates, construct identifiers and observations when available |
| Model | Main report; technical appendix; 64-state mouse and 301-state reference-adult models; mass-balance tests | Fit priority parameters to project data and report prediction intervals |
| Measurement | `measurement.md`; assay-to-state table; controls; hold-out validation design | Add actual protocol versions, instrument settings, calibration curves, raw replicate table and uncertainty |
| Safety | `safety.md`; regulatory-source links; 48-route/capsid exposure-priority screens | Complete product-specific hazard review with supervisors and institutional safety officers |
| Wiki demonstration | React atlas; disease library; 2D design space; anatomical heat map; English/Chinese UI | Integrate the built route into the final team wiki and test the deployed CSP/assets |
| Presentation | `presentation/model_engineering_script_zh.md`; compiled main report | Assign speakers and replace repository-only detail with final wet/dry-lab handoffs |

The official 2026 medal page requires standard Attribution, Contribution and
Engineering pages. The model and measurement materials are award-oriented and
should therefore emphasise reproducibility, decision impact and validation,
not only mathematical complexity.
