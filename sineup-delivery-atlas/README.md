# SINEUP Delivery Atlas frontend

This React/vinext application visualises versioned outputs from the AAV PBPK,
intracellular-transduction and SINEUP-PD models. It is the interactive layer of
the parent `iGEM_ODE` repository, not a standalone clinical calculator.

## Main views

- expandable disease-to-gene library with Chinese/English interface;
- capsid design space: organ specificity versus effective duration;
- route- and capsid-selectable reference-human anatomical heat map;
- dose-adjustable safety–efficacy windows with organ AUC margins and SINEUP
  response duration;
- absolute exposure and within-capsid relative colour mapping;
- evidence, species, model-status and source labels.

## Data contract

The page reads files under `public/data/`:

| File | Generated by |
|---|---|
| `model-results.json` / `.csv` | `../model/export_delivery_design_space.py` |
| `human-spatial-results.json` | `../model/export_delivery_design_space.py` |
| `safety-screen.json` | `../model/export_safety_screen.py` |
| `aav_safety_organ_margins.csv` | `../model/export_safety_screen.py` |
| `aav_safety_evidence.csv` | `../model/export_safety_screen.py` |
| `gene-expression.json` | `scripts/fetch-gene-expression.mjs` |

The browser filters the PBPK exports and runs the compact three-state SINEUP
PD model locally for interactive dose exploration; it does not refit PBPK
parameters or claim a clinical NOAEL.

## Local development

Node.js `>=22.13.0` is required.

```bash
npm install
npm run dev
```

To verify a release:

```bash
npm run lint
npm test
```

## Regenerate model data

Run from the repository root after installing `requirements.txt`:

```bash
python model/export_parameter_registry.py
python model/export_delivery_design_space.py \
  --output sineup-delivery-atlas/public/data/model-results.json
python model/export_safety_screen.py
```

## Interpretation

The human view uses reference physiology with exploratory capsid and route
parameters. Relative mapping defines the selected capsid's maximum region/time
scale as 100%; absolute mapping preserves one scale across the selected time
window. Neither mode establishes a safe or effective human dose.
